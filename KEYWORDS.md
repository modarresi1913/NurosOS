## Long-Form Description (for indexing)

### English

NurosOS is an open-source, Apache-2.0 licensed experimental substrate for synthetic development, written in Rust and Python. It provides the runtime, interfaces, environments, developmental mechanisms, observability, and reproducibility infrastructure required to instantiate, develop, measure, fork, replay, and compare artificial cognitive systems. The fundamental object is not MODEL but TRAJECTORY; not AGENT but DEVELOPING ORGANISM.

The central research question is: *What happens when we stop programming the final behavior of an artificial mind and instead program the conditions under which its cognitive structure can develop?* Traditional AI follows the inversion `Model -> Training -> Agent`. NurosOS inverts this again: `Developmental Genome -> Environment -> Experience -> Development -> Individual Cognitive Trajectory -> Artificial Organism`.

The system is organized as a two-layer stack. Layer 1 is the `nuros-dev` Rust crate, exposed to Python via PyO3 as `nuros._dev`. It provides the developmental substrate: `DevelopmentalGenome`, `DevelopmentalState`, `LifecycleMachine`, `ResourceWorld`, `ChangingWorld`, `MinimumOrganism` (a deterministic cognitive engine), `DevelopmentalTrajectory`, `DevelopmentalDivergence`, `MindCheckpoint`, `ReplayFidelity`, `MindDiff`, `DevelopmentalCausalityGraph`, `DevelopmentalTelemetry`, and `ReproducibilityManifest`. Layer 2 is the Python cognitive layer (`nuros/` package) with mind contracts (memory, self-model, imagination, values, body, responsibility), epistemic kernel, homeostasis kernel, safety kernel, and the Organism-0 through Organism-5 ladder.

The flagship experiment, *Same Genome / Different World*, instantiates two organisms from the same developmental genome, places them in differently-seeded `ResourceWorld` environments, develops both for the same number of steps, and measures the developmental divergence between them. The experiment demonstrates **Computational Developmental Divergence**: identical initial computational conditions producing divergent developmental states under different environmental histories. For 300 steps with seeds 1 and 999, the measured divergence is: reward_distance=1.4341, prediction_error_distance=1.3941, action_distance=2/300, mean_state_distance=0.0019.

NurosOS does NOT implement consciousness, does NOT create biological life, and does NOT solve artificial consciousness. The divergence measured by the flagship experiment is an observable computational fact, not evidence of subjective experience. NurosOS treats consciousness, sentience, subjective experience, and artificial life as open research questions, not as solved problems.

### فارسی (Persian)

NurosOS یک بستر آزمایشگاهی متن‌باز با مجوز Apache-2.0 برای توسعه‌ی مصنوعی (Synthetic Development) است که با زبان‌های Rust و Python پیاده‌سازی شده است. این سیستم runtime، رابط‌ها، محیط‌ها، مکانیزم‌های رشد، قابلیت مشاهده‌پذیری، و زیرساخت تکرارپذیری مورد نیاز برای instantiate، develop، measure، fork، replay و compare کردن سیستم‌های شناختی مصنوعی را فراهم می‌کند. شیء بنیادی نه MODEL بلکه TRAJECTORY است؛ نه AGENT بلکه DEVELOPING ORGANISM.

سؤال پژوهشی مرکزی این است: *وقتی برنامه‌نویسی رفتار نهایی یک ذهن مصنوعی را متوقف می‌کنیم و به‌جای آن شرایطی را برنامه‌نویسی می‌کنیم که ساختار شناختی آن می‌تواند در آن رشد کند، چه اتفاقی می‌افتد؟* هوش مصنوعی سنتی از وارونگی `Model -> Training -> Agent` پیروی می‌کند. NurosOS این را دوباره وارون می‌کند: `Developmental Genome -> Environment -> Experience -> Development -> Individual Cognitive Trajectory -> Artificial Organism`.

آزمایش پرچمدار، *Same Genome / Different World*، دو موجود را از یک genome توسعه‌ای یکسان instantiate می‌کند، آن‌ها را در محیط‌های `ResourceWorld` با seed‌های متفاوت قرار می‌دهد، هر دو را به مدت steps برابر develop می‌کند، و divergences رشدی بین آن‌ها را اندازه می‌گیرد. این آزمایش **Computational Developmental Divergence** را نشان می‌دهد: شرایط اولیه‌ی محاسباتی یکسان، حالت‌های رشد متفاوتی تحت تاریخچه‌های محیطی متفاوت تولید می‌کند. برای ۳۰۰ step با seed‌های ۱ و ۹۹۹، divergence اندازه‌گیری‌شده: reward_distance=1.4341، prediction_error_distance=1.3941، action_distance=2/300، mean_state_distance=0.0019.

NurosOS آگاهی را پیاده‌سازی نمی‌کند، حیات بیولوژیکی ایجاد نمی‌کند، و مشکل آگاهی مصنوعی را حل نمی‌کند. divergence اندازه‌گیری‌شده توسط آزمایش پرچمدار یک واقعیت محاسباتی قابل مشاهده است، نه شاهدی بر تجربه‌ی ذهنی.
